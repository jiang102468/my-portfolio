## 项目背景

一款提供门诊、住院等全方位一站式服务的医疗健康平台小程序，链接线上与线下服务，致力于打造高效、便捷、友好的就医体验。本次改版聚焦核心就医动线（挂号 / 缴费 / 报告 / 住院），重新梳理信息架构与视觉语言。

> 目标：让用户在 3 步以内完成一次预约挂号，让复杂就医流程在手机上变得轻量、清晰、可信。

## 我的职责

- 业务目标拆解与用户访谈梳理
- 信息架构重构与交互原型
- 视觉规范制定（色彩 / 字体 / 图标 / 组件）
- 首页与预约挂号全流程高保真设计
- 页面总览与交付标注

## 设计过程

### 调研与洞察

通过定性用户访谈与业务目标拆解，梳理出三类核心用户与高频动线：门诊预约、报告查询、住院服务。老版本的核心问题是入口层级过深、信息密度失衡、视觉缺乏医疗产品应有的可信感。

### 方案与迭代

重新设计首页信息层级，将高频服务前置；规范统一的视觉 token 与组件；针对预约挂号动线输出完整交互原型，覆盖异常态与空状态。

### 最终产出

- 完整高保真页面（首页 / 预约挂号 / 缴费 / 报告 / 住院）
- 视觉规范与组件化标注
- 可点击交互原型

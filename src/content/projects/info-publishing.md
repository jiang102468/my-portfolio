## 项目背景

信息发布系统（Information Publishing System）是面向零售连锁门店的信息管理平台，用于统一管控终端设备与内容发布流程。系统覆盖数据概览、终端管理、资源管理、任务管理、审批与用户权限等完整链路，支撑总部到门店的规模化运营。

> 核心挑战：复杂业务链路 + 多角色权限 + 海量终端数据的可读性。

## 我的职责

- B 端全链路产品梳理与页面设计
- 数据概览与信息展示多样性方案
- 构建设计系统，统一组件与视觉标准
- 跨角色流程（发布、审批、终端管控）交互设计

## 设计过程

### 调研与洞察

零售连锁场景下，总部运营、区域管理员、门店店长等角色诉求差异大；终端数据量大、信息层级深。核心痛点是页面信息密度过高、缺乏统一规范，导致多业务线各自为政。

### 方案与迭代

先定义设计系统基础（色彩 / 字体 / 间距 / 组件 token），再以数据概览为切入点解决信息展示多样性；围绕发布 → 审批 → 终端生效的主链路重构流程，降低操作成本。

### 最终产出

- 全链路页面设计（概览 / 终端 / 资源 / 任务 / 审批 / 用户）
- 信息展示多样性的多种布局方案
- 统一设计系统与组件库
